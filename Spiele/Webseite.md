Bevor wir unseren ersten Prompt schreiben, müsst ihr zuerst eine Datei herunterladen:

https://app.notion.com/p/Hier-kannst-du-dir-die-Datei-herunterladen-4012d95281748042ad29dabca22eb4bd

Wenn wir LM Studio direkt nutzen, um Code zu erstellen, dann wird der Code direkt im Chat ausgegeben und ihr müsst diesen erstmal selbstständig in eine Datei einfügen, damit ihr das Spiel starten könnt. Damit es nicht zu kompliziert für euch wird,  habe ich euch eine UI erstellt, bei der ihr weiterhin direkt mit der KI schreiben könnt, aber euer Code automatisch in eine Datei eingefügt und beim klicken auf den Knopf “Absenden” dieses ausgeführt wird. Dieses könnt ihr jederzeit während dem Kurs und auch privat nutzen, auch wenn ihr keine Internetverbindung habt. Hierfür müsst ihr nur die Datei herunterladen und in einem Browser öffnen.

Außerdem müssen wir in LM Studio paar Änderungen vornehmen. Zuerst gehen wir links unten über das Zahnrad in die Einstellungen. Bei den Einstellungen klicken wir nun auf den Dritten Reiter “Developer”. Hier müssen wir den Knopf zu “Developer Mode” anschalten. Wir können die Einstellungen schließen. Als zweites gehen links oben auf “Model Server”. Hier müssen wir oben auf “Server Settings” klicken und den Knopf “Enable CORS” anschalten. Das ermöglicht der UI auf dem Browser direkt mit der LM Studio zu kommunizieren. Anschließend klicken wir oben links bei Status: Stopped auf den Knopf, damit die KI laufen kann. Im Chat Bereich könnt ihr hier oben euer Modell auswählen, dass ihr verwendet möchtet. Ich werde anstelle dem Qwen2.5-Coder-7B-Instruct Modell das 14B Modell verwenden.  

Wenn ihr die Datei im Browser offen habt, müsst ihr einmal die Seite neu laden. Wenn oben rechts Verbunden und das Modell steht, was ihr nutzen wollt, dann passt alles.

Nun wären wir Startklar fürs Vibe Coding.
