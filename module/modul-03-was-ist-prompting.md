#### <u>Was ist ein Prompt ?</u>

Ein Prompt ist eine Beschreibung, die du einer KI gibst.

Du schreibst der KI in ganz normalen Sätzen, was du möchtest, so wie du einer anderen Person etwas sagen würdest.

Zum Beispiel „Erstelle ein einfaches Pong-Spiel.“ oder „Erstelle ein Spiel, bei dem ich mit den Pfeiltasten einen Ball einsammeln muss.“

Die KI liest deinen Prompt und versucht daraus ein Programm beziehungsweise ein Code zu erstellen.

#### <u>Warum versteht die KI manche Dinge falsch ?</u>

Manchmal die KI deine Idee nicht so versteht, wie du sie gemeint hast.

Das liegt oft daran, dass der Prompt zu ungenau ist oder wichtige Informationen fehlen.

Außerdem kann eine KI Fehler machen oder Informationen erfinden.

Deshalb solltest du das Ergebnis immer testen und überprüfen. Wenn du bemerkst, dass etwas nicht passt, kannst du das das KI beschreiben, damit sie es verbessert.

#### <u>Gute und schlechte Prompts</u>

Hierfür habe ich zwei Prompts vorbereitet.

Ein schlechter Prompt kann *„Mach ein Spiel.“ sein.*

Die KI weiß jetzt nicht,

- Welches Spiel es machen soll,
- Wie es aussieht oder
- Was das Ziel ist?

Ein besserer Prompt wäre: 

*„Erstelle ein Pong-Spiel für den Browser. Der Spieler steuert den linken Schläger mit den Tasten W und S. Es soll einen Punktestand geben und der Ball soll von den Wänden abprallen.“*

Dieser Prompt enthält viel mehr Informationen. Deshalb kann die KI deine Idee besser umsetzen.

#### <u>Wie verbessert man seine Prompts ?</u>

Wenn dir das Ergebnis nicht gefällt, musst du nicht den ganzen Prompt neu schreiben.

Du kannst der KI einfach erklären, was sie ändern soll.

Zum Beispiel:

- „Ändere den Hintergrund zu einem Fußballfeld.“
- „Füge einen Timer hinzu.“
- „Mache den Ball größer.“

So arbeitest du Schritt für Schritt mit der KI zusammen.

Diesen Vorgang nennt man iteratives Verbessern.

Wenn du merkst, dass die KI deine Idee anders umsetzt als du es wolltest, dann schreibst du diesem so genau wie möglich alle deine Verbesserungen auf. Du kannst so viele Sätze schreiben, wie du möchtest. 

#### <u>Fassen wir noch einmal zusammen</u>

- Ein Prompt beschreibt deine Idee
- Je genauer dein Prompt ist, desto besser kann die KI helfen
- Die KI kann Fehler machen, deshalb solltest du das Ergebnis immer testen und deinen Prompt bei Bedarf verbessern

Deine Merkhilfe: Je genauer dein Prompt ist, desto besser versteht die KI deine Idee.
